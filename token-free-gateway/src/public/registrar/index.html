#2 当前提供 CLI 工作流，未提供任务控制 HTTP API。本页不会启动注册、发放密钥或连接外部站点。凭证存在和质量评级不代表调用成功；不会自动导入网关。

哪些文件可以导入？

可导入 discovered-sites.json、accounts.json、credentials-2api.json，以及 discover、probe、plan、pipeline 输出的完整 JSON 对象或数组。不支持混有日志的终端文本、JSONL、keys 或 env 文件。

每次导入替换当前报告，不会自动补齐缺失阶段。账号邮箱、密码、完整 URL 路径、请求头和密钥值均不展示；脱敏摘要仅用于审阅，不是原始凭证备份。
